# 🎮 Proyectos Godot

Este repositorio contiene una colección de proyectos desarrollados con el motor de videojuegos [Godot Engine](https://godotengine.org/). Está pensado como un espacio de práctica, experimentación y crecimiento en el desarrollo de videojuegos, tanto en 2D como en 3D.

## 🚀 ¿Qué encontrarás aquí?

- Proyectos completos o prototipos hechos con Godot.
- Experimentos con mecánicas, shaders, físicas y animaciones.
- Sistemas reutilizables como menús, inventarios, controladores, cámaras, etc.
- Referencias y recursos útiles para futuros proyectos.

## 🛠️ Estructura del repositorio

```plaintext
📁 godot-projects/

```
Cada carpeta contiene un proyecto independiente de Godot. Puedes abrir cualquier proyecto directamente desde el **Project Manager** de Godot.

## 📦 Requisitos

- **Godot Engine** (versión recomendada: 4.x o superior).
- Un entorno de desarrollo opcional como VS Code o Rider, si se trabaja con GDScript o C#.

## 🧠 Objetivo del repositorio

Este repositorio sirve como:

- Diario de aprendizaje con Godot.
- Base para ideas futuras.
- Portafolio personal para mostrar habilidades en desarrollo de videojuegos.
